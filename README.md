# AK Website Agency

Business website for AK Website Agency — custom websites, SEO, Google Ads setup, and maintenance for small businesses and nonprofits in Alaska and Hawaii. Built with [Next.js](https://nextjs.org) (App Router) and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Pages

- `/` — Home
- `/services` — Services & pricing
- `/portfolio` — Portfolio
- `/process` — How it works
- `/about` — About
- `/contact` — Contact
- `/terms` — Terms of Service
- `/refund-policy` — Refund Policy
- `/privacy` — Privacy Policy

## Deploy

Import this repo into [Vercel](https://vercel.com/new) — the Next.js framework is auto-detected, no config needed.

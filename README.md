# UnifiedOps

Marketing site for UnifiedOps — websites and marketing systems for contractors. Built with [Next.js](https://nextjs.org) (App Router) and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Pages

- `/` — Home
- `/products` — Product details
- `/pricing` — Pricing
- `/trades` — Trades we serve
- `/process` — Our process
- `/about` — About
- `/contact` — Contact

## Deploy

Import this repo into [Vercel](https://vercel.com/new) — the Next.js framework is auto-detected, no config needed.
